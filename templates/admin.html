Painel Administrativo

Gestão de Funcionários e Pontos

A versão atual do Dashboard exibe dados em tempo real. As funções de gerenciar pontos (Adicionar/Remover Horas) e Resetar Banco de Dados devem continuar a ser feitas via Comandos no Discord para garantir o log no canal correto. Esta interface será expandida em futuras atualizações para permitir ações diretas.

Comandos Rápidos no Discord

  • /addtempo @user <horas> <minutos> <motivo> - Adiciona horas.
  • /deltempo @user <horas> <minutos> <motivo> - Remove horas.
  • /editar_funcionario @user <motivo> [novo_callsign] [novo_nome] [novo_cargo] - Altera manualmente os dados de um funcionário.
  • /resetar_todos - Zera o banco de dados semanal de todos.
